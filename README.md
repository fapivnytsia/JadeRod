# Нефритовый стержень

Кликер с ритмом: води платком по стержню вверх и вниз. Если держать ровный темп, монеты капают. Если темп падает, бусины сгорают. Темп выше предельного не засчитывается. За монеты в Лавке продаются улучшения и украшения. По мазкам растёт ранг: 80 рангов на 10 ступенях.

Фон — старый плакат в сепии: солнце с лучами и звездой, дворец, заводы, колосья, падающие золотые звёзды. Ещё фонари, мудрые цитаты и музыка: три трека играют по кругу.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | разметка, вид и логика страницы |
| `rules.js` | темп, ранги и цены Лавки |
| `audio/` | музыка: три трека в AAC (`.m4a`) |

## Онлайн-режим

Страница может работать с сервером игры: тогда монеты и прогресс хранятся там, а Лавка покупает за серверный баланс. Адрес сервера задаётся параметром ссылки и в коде страницы не записан. Без него игра работает сама и хранит прогресс в браузере (`localStorage`).

## Приватность

- Шрифты подгружаются с Google Fonts.
- В браузере сохраняются только прогресс игры без сервера и настройка звука, в `localStorage`.
